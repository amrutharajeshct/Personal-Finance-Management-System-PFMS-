# Personal Finance Management System (PFMS)

## Project Overview

### Introduction

The **Personal Finance Management System (PFMS)** is a personal finance tracking application designed to help individuals manage and analyze their financial activities efficiently. The system provides a centralized platform for recording income, expenses, account transfers, and financial transactions while generating meaningful reports to support better financial planning.

This project is being developed primarily to solve a real-life problem—understanding where my salary is spent each month. Rather than using sample data, the system will store my actual financial transactions, making it both a practical daily-use application and a comprehensive SQL portfolio project.

The project follows real-world software development practices, including requirement analysis, database design, documentation, version control, and incremental development.

---

# Problem Statement

Managing personal finances manually is often difficult because financial information is spread across multiple bank accounts, UPI applications, and cash transactions. Without a centralized system, it becomes challenging to answer questions such as:

- Where did my salary go this month?
- How much did I spend on food?
- How much money did I save?
- Which expense category consumes the largest portion of my income?
- How much cash is currently available?

The absence of organized financial records makes budgeting and financial planning more difficult.

The Personal Finance Management System addresses these challenges by maintaining all financial transactions in a structured SQL Server database and providing detailed analytical reports.

---

# Project Objectives

The primary objectives of this project are:

- Record monthly salary and other income sources.
- Track daily expenses accurately.
- Manage multiple bank accounts and cash transactions.
- Categorize income and expenses for analysis.
- Record transfers between bank accounts and cash.
- Generate daily, monthly, and yearly financial reports.
- Analyze spending patterns and savings.
- Build a production-style SQL Server project using real-world data.
- Strengthen SQL Server, T-SQL, database design, and software development skills.
