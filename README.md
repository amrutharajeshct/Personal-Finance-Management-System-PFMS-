# 💰 Personal Finance Management System (PFMS)

> A SQL Server–based personal finance management system that helps track income, expenses, account balances, and spending patterns using real-world financial data.

---

## 📖 About the Project

The **Personal Finance Management System (PFMS)** is a database project built using **Microsoft SQL Server** to manage and analyze personal financial transactions.

This project was created to solve a real-life problem: **understanding exactly where my salary goes every month**.

Instead of using sample or dummy data, this project is designed to store and analyze my own financial records. It provides meaningful insights into income, expenses, savings, and spending habits while serving as a practical SQL portfolio project.

---

## 🎯 Project Objectives

* Record all income transactions.
* Record all expense transactions.
* Track money across multiple bank accounts and cash.
* Categorize expenses for better analysis.
* Monitor monthly savings and spending.
* Generate financial reports and insights.
* Improve SQL Server, T-SQL, and database design skills through a real-world project.
